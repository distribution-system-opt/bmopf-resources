`draft_bmopf_schema.json` is a **draft** copy, kept for the example networks in this directory.

It is **NOT** the final schema for the math and data model as a Task Force output, it is in draft state and is subject to change.

The home for versioned schemas is [`dsopt-schema`](https://github.com/distribution-system-opt/dsopt-schema), where maintainers can release reviewed versions with `schema-v*` tags and immutable version directories. The [historical v0.1.0 import](https://github.com/distribution-system-opt/dsopt-schema/tree/baseline/bmopf-0.1.0) proposes a versioned home for this exact schema, changing only its `$id`. Until that PR merges, this copy remains its source. The versioned import does not itself release or ratify a schema.
