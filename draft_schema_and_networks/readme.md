`draft_bmopf_schema.json` is a **draft** copy, kept for the example networks in this directory.

It is **NOT** the final schema for the math and data model as a Task Force output, it is in draft state and is subject to change.

The canonical home of the released schemas is [`dsopt-schema`](https://github.com/distribution-system-opt/dsopt-schema), which carries one immutable directory per version and the `schema-v*` release tags. Write a case against a version there, not against this copy.
